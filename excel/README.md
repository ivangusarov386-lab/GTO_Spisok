# Excel-выгрузка

Кнопка Excel создаёт `.xlsm`. Книга содержит макрос только для оформления листа
«Протокол»: он пересчитывает формулы и скрывает пустые строки между участниками
и подписями. При переключении испытания в D7 строки снова показываются или
скрываются по числу результатов. Номера скрытых строк сохраняются: строки не
удаляются и результаты не изменяются. Макрос срабатывает при открытии, изменении
ячеек, переходе на протокол и перед печатью.

В настольном Excel нужно разрешить выполнение макроса этой книги. В Excel для
браузера и других клиентах без VBA автоматическая подстройка не работает.
Без разрешённых макросов остаётся компактное расположение первого испытания.
В пустом бланке «Протокола» нет, поэтому он по-прежнему сохраняется как `.xlsx`.
Загрузчик сайта принимает оба расширения; макросы при импорте не исполняются.

## Формат ячеек

Все создаваемые столбцы, строки и ячейки на всех листах, включая скрытые, имеют
числовой формат `General` («Общий»). В условном форматировании нет временных
форматов. Время длинного бега и временные пороги хранятся строками `мин:сек`;
служебные формулы переводят их в секунды для сравнения. УИН остаются строками,
включая ведущие нули. Это формат при создании файла; Excel может сам поменять
формат ячейки после ручного ввода времени или вставки с чужим форматированием.

## Исходники и сборка VBA

- `ThisWorkbook.cls` — обработчики событий книги.
- `Module1.bas` — пересчёт и управление видимостью строк.
- `../vendor/protocol/vbaProject.bin` — проект, добавляемый в выгрузку.
- `build_vba.py` — воспроизводимая сборка из открытых исходников.

Для изменения макроса отредактируйте `.cls` / `.bas`, затем выполните:

```sh
python3 -m venv /tmp/gto-vba-build
/tmp/gto-vba-build/bin/pip install oletools==0.60.2
/tmp/gto-vba-build/bin/python excel/build_vba.py
```

Нужные Excel/VBA-метаданные взяты из официального примера XlsxWriter:
https://github.com/jmcnamara/XlsxWriter/blob/main/examples/vbaProject.bin

Исходный шаблон сохранён локально, его SHA-256 проверяется сборщиком. Лицензия
сохранена в `vendor/protocol/XlsxWriter-LICENSE.txt`. Чужие демонстрационные
макросы и кеши скомпилированного кода в выходной проект не переносятся. Excel
компилирует два собственных текстовых модуля при открытии. Сборщик независимо
читает готовый CFB через oletools и сверяет извлечённые исходники.

Для упаковки `.xlsm` используется локальный JSZip 3.10.1 (MIT/GPL, файл лицензии
рядом с библиотекой), архив npm проверен по опубликованной SHA-512 integrity.
ExcelJS сначала создаёт книгу, затем JSZip добавляет VBA, тип содержимого и
связь книги. Для обновления сайта нужно размещать новые каталоги `vendor/jszip`
и `vendor/protocol` вместе с `results.html`.

## Проверка в Microsoft Excel

В Linux можно проверить упаковку XLSM, исходники VBA и пересчёт формул в
LibreOffice, но это не подтверждает выполнение событий именно Microsoft Excel.
Перед публикацией проверьте в настольном Excel:

1. Откройте выгрузку и разрешите макросы этой книги.
2. На «Протоколе» выберите испытание с 50 результатами: видны 50 строк,
   следующей видимой строкой идут подписи; пустых клеток таблицы между ними нет.
3. Выберите испытание с 70 результатами: видны 70 строк, затем подписи.
4. Вернитесь к первому испытанию; проверьте случай без результатов и печать.
5. На «Результатах» и «Нормативах» время отображается как `12:40`, формат ячеек
   «Общий», а цвета знаков соответствуют порогам.

Автоматическая проверка скачивания, содержимого XLSM, временных значений, УИН,
форматов всех листов и отсутствия исключений в условном форматировании:

```sh
# В подготовленной облачной среде playwright и openpyxl уже установлены.
GTO_EXPORT_TEST_OUTPUT=/tmp/gto-export-check python3 excel/test_export.py
```

Тест использует только искусственные ответы API и не обращается к Google.

### Регрессия структуры VBA

`test_vba.py` проверяет точность OVBA-сжатия без дописывания пробелов, окончание
потока `dir` его терминатором, нулевое поле Starting Sector Location каталогов
CFB и полное совпадение извлечённых исходников. Предыдущая упаковка нарушала
формат потока dir и значение поля каталога; Excel удалял `xl/vbaProject.bin` при восстановлении.

```sh
/tmp/gto-vba-build/bin/python excel/test_vba.py
```

Эти проверки выявляют известные дефекты контейнера, но не заменяют открытие и
выполнение событий книги в настольном Microsoft Excel.
